# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing [levinachifie@gmail.com](mailto:levinachifie@gmail.com).

Please do not open a public issue for security vulnerabilities.

## Response

We aim to respond to security reports within 5 business days and will keep you updated on progress toward a fix.

## ♿ Accessibility

Accessibility issues are treated with the same priority as security issues. Please report broken keyboard navigation, missing ARIA labels, or reduced-motion regressions through the same channels.
